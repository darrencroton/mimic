# SAGE26 model package (stub)

This package is being imported from SAGE26 (<https://github.com/sage-home/SAGE26>, commit `11b1ae851524baadb76cfd17e0b38f8a89c07224`).

At present its physics is identical to `sage16`'s: the package was forked from `sage16`, and on mini-Millennium every output galaxy field was byte-identical to `sage16`'s per `UniqueGalaxyID`.

Its run files are in `models/sage26/input/`: `sage26_mini-millennium.yaml` and `sage26_mini-millennium-horizontal.yaml`.

The full package README will be written in a later node.
